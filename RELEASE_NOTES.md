### The folder tree

**Folders stay as you leave them.** Opening a folder elsewhere in the tree no longer collapses it the moment you navigate somewhere else.

**Folders can be collapsed.** The triangle now opens and closes a folder, and the row navigates — previously the row did both at once, so closing a folder immediately reopened it. The triangle also appears on folders that have not been opened yet, and disappears once a folder turns out to be empty.

**The divider between the tree and the file list can be dragged**, and its position is remembered.

### The file list

Rows are tighter and separated by gentle banding rather than a rule between each one. Names sit centred in their row rather than riding high, and the default window is a little narrower to suit the denser layout.
